# Surat dari Botol

Aplikasi surat interaktif berbasis React, TypeScript, dan Vite. Buka botol untuk membaca surat, unduh isi surat sebagai berkas teks, atau tampilkan pertanyaan refleksi.

## Persyaratan

- Node.js 20.19+ atau 22.12+
- npm

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

## Build produksi

```bash
npm run build
npm run preview
```

## Pemeriksaan kode

```bash
npm run lint
```
